# क्लाइंट कॉन्फ़िगरेशन मार्गदर्शिकाएँ

पहले क्लाइंट चुनें, फिर उसके इनपुट फ़ॉर्मैट की जाँच करें। इस प्रोजेक्ट के GitHub और Cloudflare लिंक प्रत्येक भाषा के लिए एक ही सामान्य URI/Base64 नोड सदस्यता देते हैं; ये उपयोग के लिए तैयार Clash/Mihomo YAML या मूल sing-box JSON प्रोफ़ाइल नहीं हैं।

निजी सदस्यता URL और क्रेडेंशियल अपने डिवाइस पर ही रखें। इन्हें सार्वजनिक रूपांतरण वेबसाइटों पर जमा न करें। दूसरे फ़ॉर्मैट की आवश्यकता हो तो प्रदाता से संगत प्रोफ़ाइल लें या लक्षित क्लाइंट के आधिकारिक कॉन्फ़िगरेशन दस्तावेज़ के अनुसार अपने डिवाइस पर तैयार करें।

## v2rayN

**आयात का फ़ॉर्मैट:** URI / Base64

### त्वरित सेटअप

1. क्लाइंट के सदस्यता या प्रोफ़ाइल अनुभाग में समर्थित नोड URL या सामान्य URI/Base64 सदस्यता जोड़ें। सदस्यता रीफ़्रेश करें और पुष्टि करें कि अपेक्षित नोड दिखाई दे रहे हैं।
2. यदि प्रोफ़ाइल में विकल्प उपलब्ध हो, तो नोड या प्रॉक्सी समूह चुनें, फिर क्लाइंट के दस्तावेज़ के अनुसार प्रॉक्सी या VPN मोड चालू करें। ऑपरेटिंग सिस्टम की VPN अनुमति केवल इंस्टॉल किए गए आधिकारिक ऐप को दें। कनेक्ट होने के बाद वास्तविक पहुँच की पुष्टि करें।
3. अपडेट विफल होने पर URL, नेटवर्क और HTTP त्रुटि जाँचें। पार्सिंग विफल होने पर फ़ॉर्मैट और कोर संस्करण जाँचें। आयात सफल हो लेकिन कनेक्शन न बने, तो रीफ़्रेश करके कोई दूसरा समर्थित नोड आज़माएँ और फिर क्लाइंट का त्रुटि लॉग देखें। सफल अपडेट या विलंब परीक्षण उपलब्धता या सुरक्षा की गारंटी नहीं है।

3. अपडेट विफल होने पर URL, नेटवर्क और HTTP त्रुटि जाँचें। पार्सिंग विफल होने पर फ़ॉर्मैट और कोर संस्करण जाँचें। आयात सफल हो लेकिन कनेक्शन न बने, तो रीफ़्रेश करके कोई दूसरा समर्थित नोड आज़माएँ और फिर क्लाइंट का त्रुटि लॉग देखें। सफल अपडेट या विलंब परीक्षण उपलब्धता या सुरक्षा की गारंटी नहीं है।

समर्थित प्रोटोकॉल और स्थापित कोर संस्करण जाँचें। नोड आयात करने से सभी नियमों, DNS सेटिंग या उन्नत फ़ील्ड के स्थानांतरण की गारंटी नहीं मिलती।
