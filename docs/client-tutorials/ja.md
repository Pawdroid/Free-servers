# クライアント設定ガイド

まずクライアントを選び、対応する入力形式を確認してください。本プロジェクトの GitHub と Cloudflare のリンクは、各言語で同じ通常の URI/Base64 ノードサブスクリプションを提供します。そのまま使える Clash/Mihomo YAML やネイティブの sing-box JSON 設定ではありません。

非公開のサブスクリプション URL と認証情報は、自分のデバイス内に保管してください。公開の変換サイトには送信しないでください。別の形式が必要な場合は、提供元から互換性のある設定を入手するか、対象クライアントの公式設定文書に従ってローカルで用意してください。

## v2rayN

**インポート形式:** URI / Base64

### クイック設定

1. クライアントのサブスクリプションまたはプロファイルの画面で、対応するノード URL または通常の URI/Base64 サブスクリプションを追加します。サブスクリプションを更新し、目的のノードが表示されることを確認します。
2. プロファイルにノードやプロキシグループの選択肢がある場合は選択し、クライアントの文書に従ってプロキシまたは VPN モードを有効にします。OS の VPN 権限は、インストールした公式アプリにのみ付与してください。接続後に実際のアクセスを確認します。
3. 更新に失敗した場合は、URL、ネットワーク、HTTP エラーを確認します。解析に失敗した場合は、形式とコアバージョンを確認します。インポートに成功しても接続できない場合は、更新して別の対応ノードを試し、クライアントのエラーログを確認します。更新や遅延テストの成功は、利用可能性や安全性を保証しません。

対応プロトコルとインストール済みコアのバージョンを確認してください。ノードをインポートしても、ルール、DNS 設定、高度な項目がすべて引き継がれるとは限りません。

[公式ガイド [中文]](https://github.com/2dust/v2rayN/wiki/Description-of-some-ui)
