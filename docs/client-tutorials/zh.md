# 客户端配置指南

先选择客户端，再核对其接受的格式。本项目每种语言的 GitHub 和 Cloudflare 链接提供相同的普通 URI/Base64 节点订阅，并非可直接使用的 Clash/Mihomo YAML 或原生 sing-box JSON 配置。

请将私人订阅地址和凭据保留在自己的设备上，不要提交到公共转换网站。如需其他格式，请向服务提供方获取兼容配置，或依据目标客户端的官方配置文档在本地准备。

## v2rayN

**导入格式:** URI / Base64

### 快速配置

1. 在客户端的订阅或配置区域添加受支持的节点链接或普通 URI/Base64 订阅。刷新订阅，确认预期节点已出现在列表中。
2. 如果配置提供可选节点或代理组，请先作选择，再按客户端文档开启代理或 VPN 模式。仅向安装的官方应用授予系统 VPN 权限，连接后确认实际访问情况。
3. 更新失败时检查地址、网络和 HTTP 错误；解析失败时检查格式和核心版本。若导入成功但无法连接，先刷新并尝试其他受支持节点，再查看客户端错误日志。更新成功或延迟测试通过并不保证可用性或安全性。

请核对支持的协议和已安装的核心版本；导入节点不代表规则、DNS 设置或高级字段都能完整保留。

[官方指南 [中文]](https://github.com/2dust/v2rayN/wiki/Description-of-some-ui)

**导入格式:** Stash / Clash YAML

### 快速配置

1. 先获取完整且兼容 Clash/Mihomo 的 YAML 配置，再将其作为本地或远程配置导入、更新并选中。上方普通订阅并不是完整 YAML 配置。
2. 如果配置提供可选节点或代理组，请先作选择，再按客户端文档开启代理或 VPN 模式。仅向安装的官方应用授予系统 VPN 权限，连接后确认实际访问情况。
3. 更新失败时检查地址、网络和 HTTP 错误；解析失败时检查格式和核心版本。若导入成功但无法连接，先刷新并尝试其他受支持节点，再查看客户端错误日志。更新成功或延迟测试通过并不保证可用性或安全性。

请核对支持的协议和已安装的核心版本；导入节点不代表规则、DNS 设置或高级字段都能完整保留。

[官方指南 [中文]](https://stash.wiki/get-started)
