# 클라이언트 설정 안내

먼저 클라이언트를 선택한 후 지원하는 입력 형식을 확인하세요. 이 프로젝트의 GitHub 및 Cloudflare 링크는 각 언어에 대해 동일한 일반 URI/Base64 노드 구독을 제공합니다. 바로 사용할 수 있는 Clash/Mihomo YAML 또는 기본 sing-box JSON 설정이 아닙니다.

비공개 구독 URL과 인증 정보는 자신의 기기에 보관하고 공개 변환 사이트에 제출하지 마세요. 다른 형식이 필요하면 제공업체에서 호환 설정을 받거나 대상 클라이언트의 공식 설정 문서에 따라 로컬에서 준비하세요.

## v2rayN

**가져오기 형식:** URI / Base64

### 빠른 설정

1. 클라이언트의 구독 또는 프로필 영역에 지원되는 노드 URL이나 일반 URI/Base64 구독을 추가하세요. 구독을 새로고침하고 원하는 노드가 표시되는지 확인하세요.
2. 프로필에서 노드 또는 프록시 그룹을 선택할 수 있다면 먼저 선택한 뒤 클라이언트 문서에 따라 프록시 또는 VPN 모드를 켜세요. 운영체제의 VPN 권한은 설치한 공식 앱에만 부여하세요. 연결 후 실제 접속이 가능한지 확인하세요.
3. 업데이트에 실패하면 URL, 네트워크 및 HTTP 오류를 확인하세요. 구문 분석에 실패하면 형식과 코어 버전을 확인하세요. 가져오기는 성공했지만 연결되지 않으면 새로고침하고 지원되는 다른 노드를 시도한 뒤 클라이언트 오류 로그를 확인하세요. 업데이트나 지연 시간 테스트에 성공해도 가용성 또는 안전성이 보장되는 것은 아닙니다.

지원 프로토콜과 설치된 코어 버전을 확인하세요. 노드를 가져와도 모든 규칙, DNS 설정 또는 고급 필드가 함께 이전되는 것은 아닙니다.

Loon은 자체 설정 및 노드 구독 형식을 사용합니다. Surge 또는 Clash와 완전히 호환된다고 가정하지 말고 각 프로토콜과 필드를 확인하세요.

### 빠른 설정

1. 클라이언트의 구독 또는 프로필 영역에 지원되는 노드 URL이나 일반 URI/Base64 구독을 추가하세요. 구독을 새로고침하고 원하는 노드가 표시되는지 확인하세요.
2. 프로필에서 노드 또는 프록시 그룹을 선택할 수 있다면 먼저 선택한 뒤 클라이언트 문서에 따라 프록시 또는 VPN 모드를 켜세요. 운영체제의 VPN 권한은 설치한 공식 앱에만 부여하세요. 연결 후 실제 접속이 가능한지 확인하세요.
3. 업데이트에 실패하면 URL, 네트워크 및 HTTP 오류를 확인하세요. 구문 분석에 실패하면 형식과 코어 버전을 확인하세요. 가져오기는 성공했지만 연결되지 않으면 새로고침하고 지원되는 다른 노드를 시도한 뒤 클라이언트 오류 로그를 확인하세요. 업데이트나 지연 시간 테스트에 성공해도 가용성 또는 안전성이 보장되는 것은 아닙니다.

지원 프로토콜과 설치된 코어 버전을 확인하세요. 노드를 가져와도 모든 규칙, DNS 설정 또는 고급 필드가 함께 이전되는 것은 아닙니다.
