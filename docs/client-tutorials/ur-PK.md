# کلائنٹس کو ترتیب دینے کی رہنمائی

پہلے کلائنٹ منتخب کریں، پھر اس کے قبول کردہ ان پٹ فارمیٹ کو دیکھیں۔ اس منصوبے کے GitHub اور Cloudflare روابط ہر زبان کے لیے نوڈز کی ایک ہی عام URI/Base64 سبسکرپشن فراہم کرتے ہیں؛ یہ Clash/Mihomo YAML یا اصل sing-box JSON کے تیار شدہ پروفائل نہیں ہیں۔

نجی سبسکرپشن کے URLs اور اسناد اپنے آلے پر رکھیں۔ انہیں عوامی تبدیلی کی ویب سائٹس پر نہ بھیجیں۔ اگر کسی دوسرے فارمیٹ کی ضرورت ہو تو اپنے فراہم کنندہ سے موافق پروفائل حاصل کریں یا مطلوبہ کلائنٹ کی سرکاری دستاویزات کی مدد سے اسے مقامی طور پر تیار کریں۔

## v2rayN

**درآمد کا فارمیٹ:** URI / Base64

### فوری ترتیب

1. کلائنٹ کے سبسکرپشن یا پروفائل والے حصے میں قبول کردہ نوڈ کا URL یا عام URI/Base64 سبسکرپشن شامل کریں۔ سبسکرپشن تازہ کریں اور تصدیق کریں کہ متوقع نوڈز نظر آ رہے ہیں۔
2. اگر پروفائل انتخاب کی سہولت دیتا ہو تو نوڈ یا پراکسی گروپ منتخب کریں، پھر کلائنٹ کی دستاویزات میں بتایا گیا پراکسی/VPN موڈ فعال کریں۔ آپریٹنگ سسٹم کی VPN اجازت صرف اسی سرکاری ایپ کو دیں جو آپ نے نصب کی ہے۔ جڑنے کے بعد حقیقی رسائی کی تصدیق کریں۔
3. اگر تازہ کاری ناکام ہو تو URL، نیٹ ورک اور HTTP کی خرابی دیکھیں۔ اگر مواد پڑھنے میں خرابی ہو تو فارمیٹ اور کور ورژن دیکھیں۔ اگر درآمد کامیاب ہو مگر کنکشن نہ بنے تو سبسکرپشن تازہ کریں، کوئی دوسرا قبول کردہ نوڈ آزمائیں اور پھر کلائنٹ کی خرابیوں کا لاگ دیکھیں۔ کامیاب تازہ کاری یا تاخیر کی جانچ دستیابی یا حفاظت کی ضمانت نہیں دیتی۔

قبول کردہ پروٹوکول اور نصب شدہ کور کا ورژن دیکھیں۔ نوڈز کی درآمد سے تمام قواعد، DNS ترتیبات یا اضافی فیلڈز کی منتقلی کی ضمانت نہیں ملتی۔

[سرکاری رہنمائی [中文]](https://github.com/2dust/v2rayN/wiki/Description-of-some-ui)
